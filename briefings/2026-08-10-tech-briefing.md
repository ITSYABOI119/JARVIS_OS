**Systems / OS**
- **Out-of-window (Aug 6) but never briefed: Linux's kernel lockdown mode has been accidentally leaving legacy I/O and memory handlers open via sysfs for nearly a decade — a fix is pending.** Lockdown is supposed to cut user-space→hardware paths (PCI BAR access, `/dev/mem` writes) under Secure Boot, and this class of gap is exactly the one your SEC-014 analysis priced (a user-space process with BAR/port access is root-equivalent with the IOMMU off). Linux's mitigation for that class had a hole; seL4's answer is structural (no caps → no access), which is the contrast worth keeping. [Phoronix](https://www.phoronix.com/news/Linux-Lockdown-Legacy-IO-Mem)

**Quantization**
- **Never briefed, submitted Aug 4: NOVA-KV — "Spend Bits Where Queries Look: KV Cache Vector Quantization with Attention-Preserving Transforms" (arXiv 2608.04074).** Vector (not scalar) quantization of the KV cache with attention-preserving transforms; at **2 bits/element** it claims to recover most of the long-context retrieval accuracy scalar methods lose, at comparable throughput. A read, not a lever — JARVIS deploys full-precision KV (TurboQuant/RotorQuant deferred) — but it's the second fresh INT2-KV paper in a week (after OptR), and the trend line is what eventually makes the ~40 MiB/inference KV re-budget worth revisiting. [arXiv 2608.04074](https://arxiv.org/abs/2608.04074)
