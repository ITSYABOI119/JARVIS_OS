**Local LLM Inference**

- **llama.cpp b10731 (Sep 1) fixes a recurrent-state *snapshot* bug in the delta-net path — and it is a state-restoration correctness bug in exactly the code family you hand-implemented.** `build_conv_state_at` wrote a *single* snapshot plane, so a speculative-decoding rollback restored a convolution history **that was never captured**; it now writes one snapshot per slot, each ending one token earlier, for both the delta-net QKV convolution and the PLE convolution. The headline number is speculative-decoding throughput (183/144 tok/s vs 123/83 on Qwen3.8-Flash-Next), but the *shape* is what transfers: your ~1200-LOC gated DeltaNet carries the same "recurrent state must be restorable to an exact earlier point" obligation, and your K/M2a warm-state respawn work is the same class of hazard one level up — a restore that silently produces plausible-but-wrong state, which no cosine or coherence check catches. Not a patch to pull; a bug class to have seen. [b10731 notes](https://freedom.tech/posts/2026-09-01-llama-cpp/) · [#28123](https://github.com/ggml-org/llama.cpp/releases/tag/b10731)

**Quantization**

- **Never briefed, ~Aug 28: SemKV — "Semantic Mixed-Precision KV Cache Quantization Guided by the Quality Cliff" (arXiv 2608.28911). The measurement is worth more than the method: uniform KV quantization does NOT degrade gracefully — it falls off a cliff.** On Llama-3.1-8B-Instruct with an affine quantizer, the quantized cache is *statistically indistinguishable from FP16* down to **2.322 code bits/value** and **collapses at 2.0** — a sharp quality cliff located in the interval (2.0, 2.322]. SemKV's own contribution is to keep every token, rank by a model-internal score, and assign two adjacent *above-cliff* precisions for a measured 6.0× storage reduction. Read, not a lever — JARVIS deploys full-precision KV — but this is the first paper in this beat that gives the KV re-budget a **measured floor** rather than a trend: it says the INT2-KV line (OptR, NOVA-KV) is operating *below* a cliff that exists, and it pairs directly with the Aug-11 alignment-collapse finding as the second independent reason to be wary of sub-2.3-bit KV. If the ~40 MiB/inference KV budget ever reopens, 2.322 is the number to start from. [arXiv 2608.28911](https://arxiv.org/abs/2608.28911)
